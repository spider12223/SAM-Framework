mod.json — Mod Manifest

Manifest (mod.json) for a Support-All-Mods content pack. Declares the mod's identity, its S.A.M framework requirements, and the class/item/plugin files it ships. S.A.M reads this at launch to load the mod.

Required: namespace, name, version, framework_min_version · any key not listed below is rejected

class.json — Custom Class

Defines a custom playable character class: its attribute modifiers, skill proficiencies, starting gear, starting spells and level-up stat growth. S.A.M registers it as a runtime class alongside the vanilla Barony classes.
