## Scope

The whole Mod Builder shell (header, nav rail, shared panels, controls) and through it all sixteen pages.
Mode: Operate. Audience: Barony players making mods with forms, and scripters; long desktop sessions.
Task: find an editor, fill fields, save, export a mod .zip. Constraint: redraw Barony's look in code with
freely licensed fonts; copy no menu art or fonts from the game. Real item icons already shipped in
`public/item-icons/` may be used.

## Direction contract

THESIS: The Mod Builder is a Barony options window. Every editor is a framed window whose sections are the
crimson option bands of Barony's Settings menu. It refuses the incumbent generic "medieval parchment" look
(brown wood panels, Palatino small caps, gradient-gold title).

OWN-WORLD: Speckled slate-stone ground; oak-and-iron pixel frames with notched corners and gold corner
rivets; crimson section bands with pixel fleur-de-lis; gold plaque buttons with dark lettering, oak plaques
for secondary actions; black option rows for inputs; Barony's gold L-bracket selector for the active item
and keyboard focus; ruby, sapphire and emerald gems as error, info and ok. Pixelify Sans for chrome,
Barlow for values and prose. Real 36px Barony item icons in the nav.

STORY: A Barony player opens it and recognises the game's own menus; finds an editor by its item icon,
fills black rows, presses a gold plaque to save or export, and the mod loads the first time.

FIRST VIEWPORT: Top: an iron bar holding a framed title plaque, "S.A.M Framework" in pixel type between
three gems, with a lit gold rail running from each gem to the frame edge. Left rail about 230px: grouped nav, each row a 36px item icon and pixel label;
the active row is a crimson plaque inside gold brackets. Main: the page's windows, each opened by a crimson
band, slate interior, black field rows; the primary action is a gold plaque.

FORM: Brief-pinned (Barony's in-game menus), first on the list. seed: none (unavailable)

Signature move: the crimson option band as every panel header.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
