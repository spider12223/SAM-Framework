[h1]S.A.M Framework (Support All Mods)[/h1]

Barony was never built to be modded. S.A.M is the layer that makes it modded anyway: a patched game that reads plain JSON and runs Lua, JavaScript or TypeScript, so a mod can be made in an afternoon by someone who has never opened C++.

[b]S.A.M is a dependency, not a playable mod.[/b] On its own it adds nothing. It is what other mods are built on. Install it once and every S.A.M mod works.

[b]Subscribing here does NOT install it.[/b] S.A.M is a modified barony.exe, and Steam cannot replace a game's program file by itself. Run the installer once. It takes a minute, and the steps are below.

[hr][/hr]

[h1]NEW IN 2.6: CUSTOM RACES WORK IN MULTIPLAYER[/h1]

Played a custom race online? Your character looks fine to you and wrong to everyone else: a white body, a limb replaced by a coloured block, a head belonging to something else.

A race's body was described using numbers that only mean something on the machine that sent them, so the other game drew whatever sat at those slots in its own table. It had already worked the body out correctly, and the host overwrote that right answer a fraction of a second later. If you ever saw a character look right for an instant after a floor loaded and then flip wrong, that was this.

Now what travels between machines is a name, never a number, and each game picks the model from its own copy of your mod.

[b]Both players need S.A.M and the same mod to see a custom race.[/b] Without it they see the creature it is built on, moving normally rather than frozen in place.

[h1]61 NEW FUNCTIONS: 184 TO 245[/h1]

All of items and inventory: read an item's real displayed name, what the stack is worth, its attack and armour; change condition, blessing, count, owner and whether it can be dropped; ask what slot it fills and what stacks with what; compare two items the way the game's own creatures do when deciding what to pick up. Plus positions, facing, distances, tile queries, seeded random and run timing.

[b]The complete reference[/b], every function and event with arguments, types, return values and host-only flags:
https://github.com/spider12223/SAM-Framework/blob/main/docs/function-reference.md

It is generated from the framework's own API definition, so it cannot fall behind the code.

[b]Writing in TypeScript?[/b] [b]sam.d.ts[/b] ships in this folder and with every release. Point your editor at it for autocomplete and type checking across the whole API.

[h1]YOUR MOD CAN THINK[/h1]

A mod here is not a guest that can only react. It can be told a player was hit and stop it. It can give a creature different numbers, or a different mind.

[b]Creatures that think for themselves.[/b] Barony runs everything in the world through a function once per frame, and until now that function was always ours. Now your script can BE it. A turret that tracks and leads a moving target. A boss that changes the rules at half health. None of it picked from a list somebody else wrote.

[b]Mods that change what happens.[/b] Most events used to be announcements after the fact. Now a mod can halve incoming damage, rewrite what a chest holds, or refuse a hit outright. And two mods that both reduce damage BOTH apply, because each sees what the last one left. That is the difference between mods that stack and mods that fight.

[b]Playing multiplayer? Install this anyway.[/b] S.A.M closes eleven memory safety holes inherited from the base game, reachable with no mods.

[h1]MAKE A MOD IN YOUR BROWSER[/h1]

Nothing to download: [b][url=https://spider12223.github.io/SAM-Framework/]S.A.M Mod Builder[/url][/b]

Build a class, item, monster, spell or effect with dropdowns and sliders, watch the JSON update live, then export a ready to use .zip. It checks your work against the same rules the game uses, so if it exports, it loads.

[h1]SCRIPTING (Lua, JavaScript, TypeScript)[/h1]

JSON says what your content [i]is[/i]. A script says what it [i]does[/i]. Drop a .lua, .js or .ts file next to any JSON and it loads automatically. TypeScript is compiled for you.

[b]72 events[/b] to react to, and now to change. [b]245 functions[/b] to act with: grant items and gold, read and set stats, apply effects, cast spells, deal or change damage, teleport, spawn monsters, run your own per frame logic, open windows, timers, saved data, screen effects, and live patching that reverts when your mod unloads.

Only two functions ever get called: [b]on_event(event)[/b] and [b]on_tick(event)[/b].

[b]Safe by design.[/b] Scripts run sandboxed with a memory cap and an instruction limit. A broken script switches itself off and writes why to the log. It cannot crash your game.

[h1]HOW TO INSTALL[/h1]

[b]1.[/b] Launch Barony once so its files exist, then close it.

[b]2.[/b] Open [b][url=https://github.com/spider12223/SAM-Framework/releases/latest]github.com/spider12223/SAM-Framework/releases/latest[/url][/b], scroll to [b]Assets[/b], and download [b]SAM_Framework_Installer.exe[/b].

[b]3.[/b] Run it. If Windows says "Windows protected your PC", click [b]More info[/b] then [b]Run anyway[/b]. It is not code signed, which is the only reason Windows warns.

[b]4.[/b] It finds your Barony folder on its own. Check the path, click [b]Install[/b]. Your original is kept as [b]barony_vanilla.exe[/b].

[b]5.[/b] Launch Barony. A shield icon and [b]S.A.M Framework[/b] at the bottom of the main menu means you are done.

[b]You only do this once.[/b] To update later, run the same installer again. It always fetches the newest version.

[b]To go back to vanilla:[/b] delete barony.exe and rename barony_vanilla.exe back, or use Steam's [b]Verify integrity of game files[/b]. Your saves are untouched either way.

[hr][/hr]

[h1]HOW TO USE A MOD[/h1]

Put the mod folder in [b]...\steamapps\common\Barony\mods\[/b], launch, click [b]Mods[/b], [b]Local Mods[/b], [b]Load Mod[/b], then [b]Start Modded Game[/b].

[b]Workshop mod?[/b] Subscribe and let Steam finish downloading first. If [b]Load Mod[/b] does nothing, it has not: close Steam fully, reopen, wait, launch.
